meshom mixed meshes for FESOM on the sphere
Set up the mesh size h, the coast and the method; run the mesh on Levante; then inspect it.
How to use this page
  1. Size h: say how big the elements should be: a base size, finer near coasts, refinement zones drawn on the map. Watch the node estimate.
  2. Coast and Method: choose the coastline and how the water is filled (the defaults are fine to start).
  3. Runs: write the run; it is built on Levante by a batch job, not in this page.
  4. Mesh: open the finished mesh (raw / smooth in Runs) and read its quality: colours, worst elements, the gates.
Hover over a button to see what it does. The map: drag to move, scroll to zoom; Globe / Flat / North / South change the projection.

Bathymetry

    
The [bathymetry] table: the depth per node that meshom run writes (depth.npy, the FESOM files); shown as the colour "depth" in Mesh.

    
    
    
    
    
    
Depth rules by area

    
[[bathymetry.regions]]: the nodes inside a box or a polygon get a rule after the core's own depth steps, in this order (a later rule wins where two overlap); a rule below the run's floor (30 m with the CORE2 levels) gives the floor. They reach the meshes of runs made from this config and those runs' writes; for one finished mesh use Tools, "Mesh depth".

    

    

  


  

    
Blocks

    
Hand-placed blocks go into the config's [[blocks]] tables (four corners, the sides, the counts). The m14 methods build them before their own blocks; a block with corners on land needs coast treatment "cut".

    
Hand blocks of this config

    

    
On the map: numbered corners (drag one to move it); sides white = cut (great circle), cyan = coast, yellow = lat (parallel), orange = offset, grey = by the core's rule. Coast and offset sides follow the coast in the run; here they are drawn straight.
