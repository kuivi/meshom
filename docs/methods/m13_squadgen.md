# m13 — cubed sphere with SQuadGen refinement tiles (`m13_squadgen`, `_spring`, `_raw`)

- **What.** After SQuadGen (P. Ullrich, github.com/ClimateGlobalChange/squadgen) and Guba, Taylor, Ullrich, Overfelt and Levy 2014 (GMD 7, 2803–2816, doi:10.5194/gmd-7-2803-2014). Equiangular cubed sphere of nb² element blocks per panel (2 nb elements per edge, area h_max²). Level map: a block needs level l where (level-0 element)/2^l > √2·h; normalised top-down with SQuadGen's 4 fill rules and the "8-neighbours' parents ≥ L−1" nesting. Per level: marked blocks quartered, the ring around them paved with LOWCONN tiles (standard 9 quads, inner corner 12 with the far-corner node merge, outer corner 6, one connecting quad per shared side edge; R edge 4 elements, far edge 2, sides 3 at 0.4/0.8), the rest quartered. Conforming, all quads, no hanging nodes (checked: each directed edge once, Euler 8). Then SQuadGen springs (k = 0.1, zero rest length, 3 rings, 20 steps — E3SM recipe), then `meshom.smooth` kind="size" 20 sweeps. `_spring` = without the size sweeps, `_raw` = tiles only. CUBIT templates not implemented (Guba et al. 2014 rate them worse: valence 6–7, narrower band).
- **Coast.** m12's cut via import (cells in water ≥ 0.4 h from the coast, one quad/triangle row to the resampled coast). Added a narrow-water term to the level map (≥ 4 elements across water, width from the facing bank, `NarrowCap`): without it the 150 km channel closes at scale 4 (54 km cells at 45° leave no edge-connected chain after the 0.4 h gaps); it does not fire at scale 1.
- **Transition band = tiles + 3 element rings** (2–4 % of quads at scale 1). The 2× jump is spread over ~3 element rows: element size ratio across edges in the band p99 1.25 / max 1.36 (disc), 1.22 / 1.26 (band) ≈ 2^(1/3) per row, against the 1.15 target (needs ≥ 5 rows). Outside the band 1.00–1.01 / 1.10. Quad θmax in the band (max / p99.9 / p99): disc raw 167.0/150.6/148.1, spring 150.7/144.2/138.6, full 143.3/140.4/135.0; band raw 148.9/138.8/128.9, spring 146.8/145.7/142.8 (the zero-length springs make the straight band worse), full 143.9/142.7/139.1. |ln s/h| p99 in the band 0.71 (disc) / 0.50 (band): tile edges are 0.4–0.8 of the coarse size where h is coarse.
- **Scale 1 (runner, `m13_squadgen` before the common smoothing, the competition runs):** disc 212 941 nodes, 0 % triangles, θmax 143.3/134.4, elem ratio p99/max 1.04/1.36, |ln s/h| p99 0.31, n3/n5/T 391/383/0 vs ρ± 26/−18, 1.7 s, 0.5 GB; band 427 242, 143.9/131.6, 1.06/1.26, 0.35, 1664/1656/0 vs 94/−86, 2.5 s; continent 198 535, 0.4 % triangles, 152.2/138.3 (coast 152.2/150.3), 1.10/1.68, 0.32 (coast 0.73, interior 0.24), 1035/1035/790, Euler −4, 6.6 s (4 s of it m12's cut), 0.8 GB; uniform 50 786 = the cubed sphere, 120.0/114.3, 0.2 s. Common `--smooth`: disc 137.1/126.6, band 134.0/128.2, continent 142.1/134.2. Gates 12/14 closed (size fidelity fails), 12–17/24 continent.
- **Scale 4:** disc/band |ln s/h| p99 0.94/0.75, elem ratio p99 1.22/1.18: the finest blocks are 217 km (4–5 h_in), so the refined squares overshoot the needed region by up to a block where g = 0.4; continent channel at level 3 (27 km vs h 60 km), |ln s/h| p99 1.2, 4.6 % triangles.
- **Against m12** (moved cubed sphere, breaks above ×2: disc 178.6/165.3 at scale 1): m13 takes ×5 (disc) and ×4 (band) at 143–144° max because the tiles add the irregular nodes m12 lacks. **Against m02/m03/m04** (0.6–1.3 % irregular interior nodes, p99.9 118–128°, |ln s/h| p99 0.13–0.31): fewer irregular nodes (disc 0.36 %, band 0.78 %, no triangles) but 15–21× ρ_c, all in the bands (≈ 3 n3 + 3 n5 per tile); worse angle tails (p99.9 131–134 raw, 127–128 smoothed) and worse size fidelity (0.31–0.35): sizes are quantised to 2^-l, so |ln s/h| reaches ln √2 = 0.35 anywhere, plus 0.5–0.7 in the bands.
- **Time.** Fastest method here: level map + tiles + quartering 0.2–0.6 s at 2–4·10⁵ nodes (tile loop is Python over ring blocks only, ~10³); springs 0.5 s; size sweeps ~1 s; the m12 cut dominates the continent.
- **Production would need.** As an all-quad global generator it is robust and fast, but the 2× quantisation contradicts the smoothness requirement: ≈ 1.26 per element row in every band, |ln s/h| ≥ 0.3. Useful as (a) a fast open-ocean base where h varies by ≤ ×2 per several hundred km, combined with r-adaptation (m12's OT) inside each level to remove the quantisation, or (b) a reference for low-valence 2:1 tiles. A transition two blocks wide (4→3→2 tiles, not tried) should bring the per-row ratio to ≈ 2^(1/5) ≈ 1.15; coasts need a boundary-fitted row rather than the cut.
